# VK4PAA-Cyberdeck---GPS-Time-Sync-SDR-Terminal-LoRa-Node
This repo contains information pertaining to the creation of a personal cyberdeck. This Cyberdeck will compliment my interest in Amateur Radio and assist me in everyday applicatioms of the hobby that can be cumbersome without dedicated hardware 


## Modules
1. GPS Precision Time Sync
2. SDR Module built upon the Nooelec NESDR V5 Platform
3. A LoRa Module that can be used for mesh communications using various protocals (Meshtastic, Meshcore, Reticulum, etc)

## Other information
This project has the intention of being beginner friendly, because of this, some parts of this project will be assisted by AI **When AI has assisted with an element of the project, this will be signposted in the section of the repo**
